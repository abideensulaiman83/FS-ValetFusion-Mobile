# FS-ValetFusion-Mobile

FS-ValetFusion-Mobile is a minimal Expo-powered React Native foundation for the ValetFusion mobile experience.

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the Expo development server:
   ```bash
   npm start
   ```

## Available scripts

- `npm start` - start the Expo development server
- `npm run android` - open the app in an Android target
- `npm run ios` - open the app in an iOS target
- `npm run web` - open the app in a web target
- `npm test` - run the TypeScript typecheck used for this starter
